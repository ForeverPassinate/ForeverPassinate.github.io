## 如何更新

1. 修改 `index.html`（或替换 `assets/photo.png` 换照片）。
2. 提交并推送到 GitHub：

```bash
git add .
git commit -m "更新简历"
git push
```

3. 稍等几分钟，刷新 https://foreverpassinate.github.io 即可看到更新。
